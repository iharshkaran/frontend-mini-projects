# 🚀 Portfolio Website

A premium developer portfolio built with:

- HTML, CSS, JavaScript
- Three.js (3D effects)
- GSAP (animations)

## ✨ Features

- Dynamic project system
- GitHub API integration
- Dark/Light mode
- Search & filter
- Responsive design

## 📂 Structure

- index.html → main structure
- style.css → styling
- script.js → logic

## 🚀 Run Locally

Just open `index.html` in browser

## 🌐 Deploy

Use GitHub Pages / Netlify / Vercel
